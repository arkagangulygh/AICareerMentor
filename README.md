# AI Personal Career Mentor 1.0

An AI-powered career platform that helps users analyze resumes, match job descriptions, identify skill gaps, and practice technical interviews.

## Features

* 🔐 JWT Authentication
* 📄 Resume Upload & AI Analysis
* 💼 Job Description Analysis
* 🎯 Resume–Job Matching
* 🧠 Skill Gap Analysis
* 🎤 AI Mock Interviews
* 📝 Weekly Technical Tests
* 📊 Career Dashboard

## Tech Stack

**Frontend:** React, Vite, Axios
**Backend:** FastAPI, Python, SQLAlchemy
**Database:** PostgreSQL (Neon)
**AI:** Google Gemini
**Deployment:** Vercel + Render
